# Ремонтная мастерская «ТехноФикс»

Веб-приложение для приёма заявок на ремонт техники, отслеживания статуса ремонта и учёта запчастей.

## Основные возможности
- **Клиент:** каталог услуг с ориентировочными ценами, регистрация и вход, заявка на ремонт (тип устройства, описание неисправности, фото), личный кабинет с историей и текущим статусом, печатная квитанция, проверка статуса по коду без входа.
- **Мастер:** список назначенных заявок, смена статуса (принята → в диагностике → в ремонте → готова к выдаче → выдана), комментарии, стоимость работ, списание использованных запчастей со склада.
- **Администратор:** канбан-доска заявок с drag-and-drop, назначение мастеров, управление услугами, сотрудниками и пользователями, склад запчастей, статистика с графиками (заявки и доход по месяцам, типы устройств, популярные неисправности, загрузка мастеров).

## Стек технологий
- **Backend:** C# (ASP.NET Core, .NET 7)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), графики на SVG
- **База данных:** SQLite (Microsoft.Data.Sqlite)

## Как запустить проект локально
1. Установите [.NET SDK 7](https://dotnet.microsoft.com/download) (или новее).
2. Скачайте проект и откройте папку `RepairApp` в VS Code.
3. В терминале выполните:
   ```
   dotnet run
   ```
4. Откройте в браузере http://localhost:5081

При первом запуске автоматически создаётся файл `repair.db` с тестовыми данными.

## Безопасность
- пароли хранятся в виде хеша PBKDF2 (SHA-256, 100 000 итераций, соль);
- доступ к API по токену Bearer, роли проверяются на сервере;
- все SQL-запросы параметризованы (защита от SQL-инъекций);
- фото проверяется по сигнатуре файла (JPG/PNG/WebP), размер до 3 МБ;
- данные валидируются и на клиенте, и на сервере.

## Структура проекта
- `RepairApp/Program.cs` - серверная логика, API, работа с БД, тестовые данные.
- `RepairApp/wwwroot/` - клиентская часть (`index.html`, `style.css`, `app.js`).
- `RepairApp/wwwroot/uploads/` - загруженные фото неисправностей.
- `RepairApp/repair.db` - база данных SQLite (создаётся при запуске).
- `docs/DATABASE.md` - ER-диаграмма и описание таблиц.
- `docs/TESTING.md` - тест-кейсы.
- `docs/USER_GUIDE.md` - руководство пользователя.


## Фотографии в каталоге

В карточках услуг используются реальные фотографии с Unsplash. Они загружаются по HTTPS при открытии каталога, поэтому для их отображения требуется подключение к интернету. Если фотография недоступна, карточка сохраняет тёмный фон и остальные элементы интерфейса.
